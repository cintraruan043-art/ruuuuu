# Figurinha — arquivos na raiz

Todos os arquivos de código e configuração estão na raiz do repositório (sem subpastas).

Para usar: extraia este ZIP e envie **os arquivos que estão dentro dele** para a raiz do GitHub. Não envie apenas o ZIP como um arquivo no repositório.

Workflow do Codemagic: `ipa-sem-assinatura`.
